# Indigo Magic

**Indigo Magic** is a procedural desktop background generator inspired by the legendary SGI Indigo Magic desktop environment and the visual aesthetics of Silicon Graphics workstations from the early 1990s through the IRIX 6.x era.

The program recreates the distinctive look of classic UNIX workstations, combining authentic IRIX-inspired textures, geometric patterns, rich color palettes, and retro computer graphics with modern customization capabilities. From the iconic Verde Marble textures and Indigo-inspired colors to intricate mathematical patterns, moiré effects, beveled geometric designs, fractals, and abstract procedural artwork, the program transforms the spirit of classic Silicon Graphics desktops into a fully customizable creative experience.

Unlike a simple collection of static wallpaper images, IRIX Background Magic generates patterns procedurally, allowing users to experiment with colors, textures, scale, density, rotation, symmetry, shading, highlights, shadows, distortion, and randomness. Users can recolor classic patterns, create entirely new combinations, and generate unique backgrounds while preserving the character of the original designs.

The program also incorporates customizable themes inspired by classic IRIX interface schemes, including their underlying color definitions and shared settings, to reproduce the distinctive appearance of historical workstation environments as faithfully as possible.

Designed as both a retro-computing tribute and a comprehensive pattern laboratory, IRIX Background Magic brings together historical authenticity and modern creative freedom. It supports saving and loading configurations, exporting generated backgrounds, reproducible random generation, and extensive customization, making it possible to build, preserve, and revisit an effectively unlimited collection of desktop designs.

**The goal:** to capture the unmistakable visual identity of SGI Indigo Magic—its elegant geometry, distinctive colors, textured surfaces, and sophisticated early-1990s workstation aesthetic—while giving users the tools to explore, customize, and create beyond the original system's limitations.
